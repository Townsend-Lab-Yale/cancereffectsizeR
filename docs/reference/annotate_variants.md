# Annotate variants

Annotates CESAnalysis MAF data with reference genome and gene data;
called by load_maf

## Usage

``` r
annotate_variants(refset = NULL, variants = NULL)
```

## Arguments

- refset:

  CES reference data set (e.g., from the ces.refset.hg19 data package)

- variants:

  MAF-like data.table of variants (e.g., as generated by preload_maf())
